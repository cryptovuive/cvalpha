📏 Bảng ký tự tối ưu

Giới hạn Twitter: 280 ký tự

Theo loại comment:
• Câu hỏi → 50-160 ký tự (lý tưởng: 100)
• Đồng ý → 20-80 ký tự (lý tưởng: 45)
• Phản đối → 60-220 ký tự (lý tưởng: 130)
• Hài hước → 15-70 ký tự (lý tưởng: 35)
• Cảm ơn → 15-50 ký tự (lý tưởng: 30)
• Bình thường → 30-150 ký tự (lý tưởng: 80)

Nguyên tắc:
• Comment ngắn → reply ngắn
• Comment dài → reply dài hơn (nhưng không quá 220)
• Luôn match "năng lượng" của comment
• Cắt thông minh tại ranh giới câu/từ nếu quá dài

🔑 OpenAI API

Đổi nếu dùng proxy hoặc OpenAI-compatible API (OpenRouter, Ollama...)

🧠 System Prompt tùy chỉnh

Thêm instruction riêng cho AI. Để trống = dùng mặc định. Prompt này được thêm vào cuối system prompt.

⏱️ Giới hạn

Random giữa 2 giá trị. 60-120s = 1-2 phút mỗi reply.
